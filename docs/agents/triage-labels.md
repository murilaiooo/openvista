# Triage label vocabulary

The project uses Matt Pocock's default triage roles. Use the exact names:

| Label | Meaning |
| --- | --- |
| `needs-triage` | Incoming work, scope not reviewed. |
| `needs-info` | Missing facts or product decisions block progress. |
| `ready-for-agent` | Approved, independently actionable and testable. |
| `ready-for-human` | A user choice, rights approval, access or manual device test is required. |
| `wontfix` | Reviewed and explicitly declined. |

The labels are intended for GitHub. If the tracker lacks them, create them before applying the triage workflow. Avoid stacking contradictory labels.
