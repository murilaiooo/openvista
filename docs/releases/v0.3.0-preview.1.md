# OpenVista v0.3.0-preview.1

Signed **development preview** for Android TV, Google TV and compatible Fire TV devices. This is the first GitHub release artifact, **not** a certified stable v1. The repository is still private, so downloads are available only to accounts with access to the repository.

## Included

- Three-panel Home, unified Settings, and the TV-matched ambient camera overlay with 32 display-care positions and optional inactivity fading.
- User-managed HLS/DASH streams, M3U lists, playlists, favorites and locally selected video files/folders. OpenVista includes **no** camera feeds, video files or stream catalog.
- Network loss/recovery, retry backoff, live-window resynchronization, source transitions and playback fallback.
- Separate source/viewer clocks and weather; localized country and flag; manual **Find location**; weather providers with their applicable attribution.
- English and Brazilian Portuguese interface and documentation.

## Privacy changes for this preview

**Automatic bulk camera-city lookup is disabled until a real opt-in control and privacy review are available.** Users can still select **Find location** in the source editor; that explicit action sends the entered city and optional country to Open-Meteo. Weather widgets may contact the configured forecast providers. The unapproved package-install permission was removed because the in-app update channel remains disabled.

## Install and upgrade

- APK application ID: `com.openvista.prototype`
- Version name: `0.3.0-preview.1`
- Version code: `3`
- Minimum Android version: 9 (API 28)
- The APK is signed with a new **OpenVista production certificate**, not with the Android development/debug key.
- **Important:** It cannot upgrade an existing `com.openvista.prototype` debug installation signed with a different certificate. Android will reject that upgrade. Do **not** uninstall a working debug installation unless you have safely exported/backed up your cameras, playlists and settings, because uninstalling may erase app data. New installations can install this signed APK normally.
- This preview has **not** completed a 24-hour unattended hardware soak, broad-device compatibility testing or installation verification of this exact signed APK. Real Hisense / Fire OS 7 evidence so far primarily covers the prior debug variant.
- APK publication does not enable the disabled in-app updater, automatic system-install privilege, or public repository visibility.
